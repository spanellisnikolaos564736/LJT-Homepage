# LJT-Homepage

Personal academic website of Junteng Liu, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

- [About](https://spanellisnikolaos564736.github.io/LJT-Homepage/) — background, research interests, education, research experience, publications, skills and contact information
- [Publications](https://spanellisnikolaos564736.github.io/LJT-Homepage/publications/)

Site configuration is in `_config.yml`, the About page is `_pages/about.md`, the publications subpage is `_pages/publications.html`, and individual publication records are in `_publications/`.
